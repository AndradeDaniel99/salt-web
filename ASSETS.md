# Mídia e atribuição

A Apache License 2.0 do repositório cobre o código-fonte, mas **não concede automaticamente direitos sobre fotografias, ilustrações, logotipos, nomes ou marcas**.

## Arquivos demonstrativos

As imagens em `public/assets/*.jpg` foram incluídas para demonstrar a interface. Sua procedência e licença precisam ser confirmadas pelo mantenedor antes de redistribuição fora deste repositório.

Até essa confirmação:

- não presuma que as imagens estão sob Apache 2.0;
- substitua-as em forks destinados a publicação ou distribuição;
- não use as imagens para representar pessoas ou organizações reais;
- não envie novas mídias sem registrar origem, autor, licença e atribuição exigida.

Os nomes, organizações, campanhas e relatos em `data/demo-catalog.json` são fictícios e não representam validação, parceria ou captação real.

## Registro exigido para novas mídias

Toda nova mídia deve documentar:

| Campo                | Exemplo                               |
| -------------------- | ------------------------------------- |
| Arquivo              | `public/assets/example.jpg`           |
| Autor ou gerador     | nome da pessoa ou ferramenta          |
| Origem               | URL ou referência do arquivo original |
| Licença ou permissão | identificador e link para os termos   |
| Atribuição           | texto exigido, quando aplicável       |
| Alterações           | corte, ajuste de cor, composição etc. |

Mídias sem esse registro podem ser removidas do projeto.
