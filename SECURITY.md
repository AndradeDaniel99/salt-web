# Política de segurança

## Versões suportadas

Enquanto o projeto estiver na série `0.x`, somente o código mais recente da branch `main` receberá correções de segurança.

## Reportando uma vulnerabilidade

Não abra uma issue pública com detalhes de uma vulnerabilidade.

Use **Security → Report a vulnerability** neste repositório para enviar um relatório privado. Inclua:

- descrição e impacto esperado;
- passos mínimos para reproduzir;
- versão, commit ou ambiente afetado;
- sugestão de correção, se houver.

Se o formulário privado ainda não estiver disponível, contate o mantenedor pelos meios publicados em seu perfil do GitHub e peça um canal privado, sem divulgar os detalhes técnicos inicialmente.

O recebimento será confirmado assim que possível. A correção e a divulgação serão coordenadas conforme gravidade, possibilidade de exploração e disponibilidade do mantenedor.

## Escopo do MVP

O fluxo de apoio atual é uma simulação local: não processa pagamentos e não coleta dados financeiros. Integrações futuras com autenticação, pagamentos ou dados pessoais deverão passar por uma nova revisão de segurança antes de serem consideradas suportadas.
